Anime-lists API (optional)

Off by default. Until you tick the box above, the plugin sends nothing to this API. A .plexmatch file is always used first and works without it.

When on: movies and series without a .plexmatch file are identified through the API, the Identify button searches it, movies get their AniDB tags and Fanart.tv artwork from the ids it supplies, and series follow the season layout it gives (so a show that TVDB splits into sagas, like Dragon Ball, keeps that layout). If a title could be two different anime, it is left unidentified and logged instead of guessed.

What is sent: the folder name and year of each movie or series being identified, plus anime ids (AniList, MAL, TVDB, TMDb) to look up their details. The server is run by the plugin author. Its logs hold only the searched title and how the request went; they contain no IP address, device id or token.
